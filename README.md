# 📚 学业成绩评估与分析系统 (Grade Management System)

一个基于纯前端（HTML + JavaScript + Tailwind CSS）构建的高颜值、多功能学业成绩与学点积分管理系统。支持多年级、双学期成绩跟踪，具备灵活的加权算分机制、交互式可视化图表以及 Google / Firebase 云端跨设备实时同步。

---

## ✨ 核心功能亮点

- 🎓 **多年级与双学期管理**：支持自定义添加/删除年级（如初一、初二、高一等），并支持切换上半年 (Sem 1) 与 下半年 (Sem 2)。
- ⚖️ **灵活的得分计算规则**：
  - **权重计算模式**：支持根据“课业”、“学习评估”、“期末考”三分项及自定义权重比例（默认 30% / 30% / 40%）自动归一化计算总分。
  - **直接填分模式**：可取消勾选权重计算，直接手动录入“最后得分”，适配不拆分细项的学科。
- 📊 **数据可视化分析**：动态生成柱状对比图（带学期平均基准线）与成绩分布环形图（优秀/中等/不及格占比）。
- 🔄 **跨学期结构一键导入**：可一键复制已有年级或学期的学科配置（名称、学点、权重比例），避免重复建科。
- 💾 **数据备份与云端同步**：
  - **本地存储**：无需登录即可使用，数据自动保存在浏览器 `localStorage`。
  - **文件导入/导出**：支持导出 JSON 全量备份文件及 CSV 成绩表格；支持随时导入 JSON 还原数据。
  - **Google 账号云同步**：接入 Firebase Firestore，登录 Google 账号后自动实现多设备实时同步。

---

## 🛠️ 技术栈

- **前端 UI 框架**：[Tailwind CSS](https://tailwindcss.com/) (CDN 引入)
- **图表渲染**：[Chart.js](https://www.chartjs.org/)
- **后端 / 云数据库**：[Firebase Auth](https://firebase.google.com/) & [Firestore](https://firebase.google.com/docs/firestore)
- **图标与字体**：Heroicons SVG & Google Font (Inter)

## 🚀 快速使用方法

因为本项目为**纯单文件 Web 应用**，无需安装复杂 Node.js 运行环境：

1. 下载项目中的文件（例如 `index.html`）。
2. 用任意现代浏览器（Chrome、Edge、Safari 等）**双击直接打开**即可开始使用！

---

## 📖 数据导出与恢复说明

- **导出 JSON**：点击导航栏右侧“导出备份 -> 导出 JSON”，将保存一份包含年级、学科及权重配置的完整的 `.json` 备份文件。
- **导入 JSON**：点击“导入 JSON”按钮选择此前保存的文件，即可瞬间恢复数据。
- **导出 CSV**：适合导入到 Excel 或 WPS 中进行打印或二次编辑。
